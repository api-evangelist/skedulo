Skedulo is the Deskless Productivity Cloud, a field service and mobile workforce management platform used by enterprises to schedule, dispatch, optimize, and track deskless workers. Its developer platform exposes 21 REST services (scheduling, availability, optimization, rules, notifications, resource tracking, geoservices, files, configuration, onboarding and more) plus a full GraphQL API, webhooks and triggered actions for real-time events, a `sked` CLI, first-party SDKs and UI components, and an MCP server. Authentication is via Bearer JWT API tokens, with regional API hosts for the US, AU, UK and CA. Backed by SoftBank Vision Fund.

**Areas:** Company · Enterprise · Scheduling · Field Service Management · Workforce Management · Deskless · Dispatch · Optimization · GraphQL · Webhook

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Skedulo: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
